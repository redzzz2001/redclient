# Red Client (Fabric 26.3)

Mod client-side simples para Minecraft Java 26.3.

## Uso

1. Instale o Fabric Loader para Minecraft 26.3 e o Fabric API 26.3.
2. Coloque o JAR deste mod e o JAR do Fabric API na pasta `mods`.
3. Entre em um mundo e pressione `Alt direito` para abrir o menu.
4. No menu, configure visão noturna, ESP, Aim Bot, Kill Aura, Fly, Jesus e Fast Mine.
5. Em Opções > Controles > Red Client, configure uma hotkey individual para cada modulo.

Use apenas em mundos próprios ou onde as regras do servidor permitirem.

## Build

```bash
./gradlew build
```

O JAR final fica em `build/libs/`.
